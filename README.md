### 📟 Command categories

1. Server Structure — Channels, roles, categories, server settings, emojis
2. Mass Actions — Ban all, kick all, mute all, nickname synchronization
3. Spam & DMs — Webhooks, direct messaging, ghost pings, reaction floods
4. Utilities — Server cloning, lockdown mode, admin escalation attempts

---

### 🚀 Installation

1. **python_installer.bat** — Checks/installs Python 3.10+
2. **setup.bat** — Installs required dependencies (discord.py, requests)
3. **start.bat** — Launches the DarkNode CLI

> Important: Your bot must be invited to the target server with Administrator permissions for all functions to execute correctly.

---

### ⚠️ Required — Bot Intents

Enable these in the [Discord Developer Portal](https://discord.com/developers/applications) before running:

*   Server Members Intent: ✅
*   Message Content Intent: ✅
*   Presence Intent: ❌  

Steps: *Applications → your bot → Bot → Privileged Gateway Intents*

### ⚡ Feature Spotlight

*   Nuke: Complete server destruction including all assets and members.
*   Ghost Ping: Mass mentions using hidden characters to avoid detection.
*   Clone: Exact replication of channel structures and role hierarchies.
*   DM Spam: Automated messaging to every user in the member list.
