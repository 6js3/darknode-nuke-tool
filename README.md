🛠️ INSTALLATION
Ensure you have Python 3.10+ installed on your system (download from https://www.python.org/downloads).
Clone this repository using Git (git clone https://github.com/DarkNode/NukeTool.git) or download the source files manually (https://github.com/DarkNode/NukeTool/archive/refs/heads/main.zip).
Run python_installer.bat to set up the necessary environment (this script installs pip, virtualenv, and required packages).
Run setup.bat to install all required dependencies (including discord.py, requests).
Launch the tool using start.bat. The first run will prompt you to enter your Discord bot token (with Administrator permissions).
